# Pico, your guitar friend

A contextual in-game helper for **Notey's World**, designed as a UX/UI take-home challenge.

Pico is a small living guitar pick that stands next to the strings. It reacts to what the player plays, helps when the player seems stuck, and works as a permanent help button that opens lessons or troubleshooting on demand. The design is built for young players (ages 6 to 13) on a landscape tablet, using audio recognition as input.

The page explains the thinking and lets you walk through every screen state:

- the three jobs of Pico (buddy, automatic helper, help button)
- an interactive user flow, where each box opens its screen in the walk through
- design notes: the principles behind the prototype
- rules and thresholds, listed as assumptions to test with real players
